# BookStack QMS (mit Freigabe-Workflow)

Home-Assistant-Add-on: BookStack v25.11.3 (auf Basis des offiziellen
Community-Add-ons v4.0.2) mit zusätzlicher QMS-Freigabefunktion nach dem
4-Augen-Prinzip – für die SOP-Verwaltung in der Apotheke.

**Funktionen**

- Automatischer Status „In Prüfung“ bei jeder neuen oder geänderten Seite
- Rolle „Freigeber“: nur sie (oder Admins) dürfen freigeben/zurückweisen
- 4-Augen-Prinzip: eigene Änderungen können nie selbst freigegeben werden
- Farbige Status-Banner (gelb/grün/rot) auf jeder Seite
- Revisionssicheres Freigabe-Protokoll unter `/qms/protokoll`
- Komplett auf Deutsch

Installation und Migration: siehe [DOCS.md](DOCS.md).
